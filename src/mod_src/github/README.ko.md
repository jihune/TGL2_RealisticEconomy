# Realistic Economy, This Grand Life 2 모드

버전 1.0.0 · 게임 v1.03.22 전용 · 비공식 모드

[English](README.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Français](README.fr.md) · [Português (Brasil)](README.pt-BR.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md)

This Grand Life 2 의 돈 흐름을 현실에 가깝게 바꾸고, 예전 세이브를 불러와서 이득을 보는 길을 막습니다. 새 창이나 새 버튼은 만들지 않습니다. 게임에 있는 화면 안에서 동작하고, 모드의 글은 게임의 언어(여덟 개 모두)로 나옵니다.

## 새로 생기는 것

### 대출과 현금
- 대출 금리가 가계의 신용등급(AAA ~ B)과 모기지의 담보 비율을 따릅니다.
- 이번 월말에 나갈 현금이 월간 요약에 미리 나옵니다.
- 값보다 많이 싸게 나온 부동산 매물을 월간 요약이 알려 줍니다.

### 세이브를 불러와도 이득이 없습니다
- 이미 지난 월말보다 앞의 세이브를 불러오면, 그 월말을 다시 지날 때까지 주식과 선물 거래가 잠깁니다.
- 카지노 게임은 판돈과 확률이 정해져 있고 게임마다 한 달에 한 번입니다. 결과는 불러와도 그대로입니다.
- 그 달의 채용 지원자는 불러와도 바뀌지 않습니다.

### 주식
- 회사마다 PER, PBR, 배당 수익률, 전월 대비 주가, 적정 주가가 나옵니다. 파산이나 증자가 가까운 회사는 미리 경고합니다.
- 조사 구독: 회사를 Shift-클릭해 두면 달마다 조사를 새로 합니다.
- 회사를 상장하면 지분 45% 를 지키고 나머지는 현금으로 받습니다. 지분 20% 마다 이사회 한 자리가 보장됩니다.
- 회사 목록과 선물 목록의 정렬 순서가 늘고, 차트에 6개월 보기가 생깁니다.

### 사업체
- 채용 창이 일 한 시간에 드는 돈(시급 ÷ 효율)을 보여 주고 싼 순으로 줄 세웁니다.
- 사업체마다 일을 모드에 맡길 수 있습니다. 직원(모자란 일손 채용, 남는 직원 내보내기, 급여 인상 요구에 답하기), 모자란 자산 구매, 광고, 계약 체결, 면적 늘리기입니다. Ctrl+Shift-클릭 한 번이면 사업체를 통째로 맡깁니다.

### 게임 원래의 문제를 고친 것
- 세이브를 여러 번 불러오면 게임이 꺼지던 문제.
- 번역이 틀리거나 깨져 나오던 글(한국어가 가장 많습니다)과 사람 이름의 깨진 글자.
- 마친 교육(학위, 자격증)의 값이 달마다 깎이던 것.

## 설치
1. 게임을 끕니다. Releases 의 zip 을 게임 폴더(`TGL2.exe` 가 있는 폴더)에 풉니다.
2. `RealisticEconomy_install.bat` 을 더블클릭합니다. 먼저 세이브를 `saves_before_RealisticEconomy_1` 폴더에 복사해 둡니다.
3. 게임을 켭니다. 메인 메뉴 오른쪽 아래의 버전이 "v1.03.22 + Realistic Economy"로 나옵니다.

지울 때는 `RealisticEconomy_uninstall.bat` 을 실행합니다. 모드를 쓰며 저장한 세이브는 모드 없이도 열립니다.

## 쓰는 법
대부분은 저절로 됩니다. 직접 누르는 것은 아래 표가 전부이고, 그 자리에 마우스를 올리면 나오는 설명 글에도 적혀 있습니다.

| 어디서 | 누르는 법 | 하는 일 |
|---|---|---|
| 주식 창의 회사 목록 | 회사를 Shift-클릭 | 그 회사의 조사 구독을 켜고 끕니다 |
| 같은 목록 | Ctrl+Shift-클릭 | 모든 회사의 조사 구독을 켜고 끕니다 |
| 사업체 창의 광고 아이콘 | Shift-클릭 | 광고를 모드에 맡기고, 다시 하면 되찾습니다 |
| 사업체 창의 계약 아이콘 | Shift-클릭 | 계약 체결을 모드에 맡기고, 다시 하면 되찾습니다 |
| 사업체 창의 광고 아이콘 | Ctrl+Shift-클릭 | 사업체를 통째로 맡기고, 다시 하면 되찾습니다 |
| 직원 탭의 자동 관리 스위치 | 클릭 | 그 사업체 직원 모두의 자동 관리를 켜고 끕니다 |
| 사업체의 "낡은 자산 자동 구매" 스위치 | 클릭 | 모자란 자산도 모드가 삽니다 |

기능은 `RealisticEconomy.ini` 에서 하나씩 끌 수 있습니다. 자세한 설명서는 zip 안의 `RealisticEconomy_README_ko.txt` 입니다.
