# Realistic Economy

This Grand Life 2 のMODです。ゲーム v1.03.22 専用、MODのバージョンは 1.4.0 です。ゲームの開発元が作ったものではありません。

ほかの言語: [English](README.md), [한국어](README.ko.md), [Deutsch](README.de.md), [Español](README.es.md), [Français](README.fr.md), [Português (Brasil)](README.pt-BR.md), [简体中文](README.zh-CN.md)

## ローンの金利が信用格付けで決まります

![借金にマウスを置くと、金利の横に信用格付けが出る](img/ja/loan.png)

金利 = 中央銀行金利 + 上乗せ金利。上乗せ金利は世帯の信用格付け(AAA ~ B)で決まります。借金が少なく、収入と現金が多いほど格付けが良くなります。

## 上場すると現金を受け取ります

![「株式会社を設立する」ウィンドウ](img/ja/ipo.png)

元のゲームでは株式の 25% だけを受け取り、現金はありません。MODでは 45% を持ち、残りの 55% を上場価格で売った現金を受け取ります。上場料の下の小さな行がその金額です。

## 株式: 指標、調査の購読、取締役会の席

![株式ウィンドウ](img/ja/stocks.png)

- 株価の横に、先月からの変化率、PBR、PER、配当利回りが出ます。
- 会社を Shift+クリックすると調査を購読します。MODが手数料を取って毎月調査し直し、適正株価を表示します。Ctrl+Shift+クリックはすべての会社を購読します。
- 上場会社の株式 20% ごとに、取締役会の1席が保証されます。選挙のある月に世帯のメンバーを指名します。

![月間サマリー](img/ja/summary.png)

調査の結果と手数料、今月末に必要な現金は月間サマリーに出ます。

## チャート

![会社のチャート](img/ja/chart.png)

会社のチャートは株価の線だけを表示した状態で開きます。線ごとに色が違い、名前の横に最後の値が付きます。期間ボタンに6か月が加わりました。

## ビジネスの自動化

![広告アイコンの説明文](img/ja/automation.png)

従業員、資産、広告、契約を、ビジネスごとに1つずつMODに任せられます。広告アイコンを Ctrl+Shift+クリックすると全部任せます。操作はアイコンの説明文に書いてあります。任せられるのは、世帯が自分の会社を一度上場（IPO）した後からです。人手の足りない数時間は、守れる評判より安ければ外注か採用で埋めます。

![採用タブ](img/ja/hire.png)

採用タブは、同じ仕事を安くできる人から順に表示します(時給 ÷ 作業効率)。

## 直したゲームのバグ

- セーブを数十回ロードするとゲームが終了する問題
- いくつかの言語の誤った翻訳
- 人名の文字が四角で表示される問題
- 銀行が承認した額より大きい住宅ローンが組まれる問題
- 毎月の自動振替が現金なしで株を買う問題
- 取締役会の選挙で同点になるとゲームが終了する問題
- 建設の契約の1つが土木技師を求めない問題

## 好みが分かれる機能と、オフにする方法

ゲームのルールや数値を変える機能は以下ですべてです。ゲームのフォルダにある `RealisticEconomy.ini` で値を 0 にすると、その部分は元のゲームに戻ります。

| 機能 | ゲームとの違い | オフにする設定 |
|---|---|---|
| バランス | 株式の手数料 2%(ゲーム 1%)、先物の手数料はマージンの 10%(1%)、普通預金の金利が上がり現金にも利息、更新時に下がることもある家賃、新しいビジネスは認知度 25% から(0%) | `[features] balance=0` |
| ロード後の取引ロック | 前のセーブをロードすると、その月がもう一度過ぎるまで株式・先物の取引ができません。その月の株価と売り物件はロードしても同じです | `[features] guard=0` |
| 信用格付けによる金利 | ローンの金利が世帯の信用格付けで決まります | `[features] credit=0` |
| 上場 | 45% を持ち、残りを売った現金を受け取ります(ゲーム: 25%、現金なし) | `[features] ipo=0` |
| 取締役会の席 | 株式 20% ごとに1席を保証 | `[features] board=0` |
| カジノ | 決まった賭け金と確率、各ゲーム月1回 | `[features] casino=0` |
| 修了した教育 | 数値が下がりません | `[features] experience=0` |
| ビジネスの自動化 | 任せたビジネスでだけ、MODが従業員・資産・広告・契約を管理します。同じクリックで取り戻せます | `[features] business=0` |
| 競争 | 業種の市場で企業の分を 1.25 倍に数え、競争が早く始まります | `[balance] competitionWeight=1` |
| 評判のボーナス | ビジネスの月末の「完了した作業」ボーナス（3.6ポイント）が、残した作業の割合に応じて減り、2%でゼロになります。1時間残しただけで丸ごと失うことはなくなります | `[balance] reputationBonusFade=0` |
| お金で影響力 | 銀行に大きな寄付が二つ($1M、$10M)、市の政策投票は 12 か月ごと(ゲーム 24 か月)、ゲーム本来の寄付は年に一度(ゲームは毎月) | `[features] influence=0` |
| パーソナルコーチング | 病院でお金を払うと、選んだ好みが「好き」に一段階近づきます(1人につき年に1つ) | `[features] coaching=0` |

バランスの数値は `[balance]` に1行ずつあります。

## そのほかの機能

設定ファイルで1つずつオフにできます。

- その月の採用候補者はロードしても同じ
- 価値より大幅に安い物件が売りに出たときのお知らせ

## インストール

1. ゲームを終了します。
2. [Releases](../../releases) のzipをゲームのフォルダ(`TGL2.exe` がある場所)に展開します。
3. `RealisticEconomy_install.bat` を実行します。最初にセーブを `saves_before_RealisticEconomy_1` へコピーします。

削除するときは `RealisticEconomy_uninstall.bat` を実行します。設定は `RealisticEconomy.ini` にあります。詳しい説明書は英語です: [docs/RealisticEconomy_README_en.txt](docs/RealisticEconomy_README_en.txt)

ウイルス対策ソフトが `version.dll` を警告することがあります。公開されている Ultimate ASI Loader です。ゲームがアップデートされると、MODは自分でオフになります。
