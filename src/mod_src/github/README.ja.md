# Realistic Economy

This Grand Life 2 のお金のルールを変えるMODです。借金の多い世帯はローンの金利が高くなります。来月の株価を見てから前のセーブをロードして買う方法は通用しなくなります。カジノで負けたあとにセーブをロードしてやり直す方法も同じです。株式ウィンドウには会社を判断するための数字が加わります。ビジネスが増えると手間のかかる採用、広告、契約はMODに任せられます。ゲーム本体の不具合もいくつか直します。

ゲーム v1.03.22 でのみ動作します。ゲームの開発元が作ったものではありません。現在のバージョンは 1.0.0 です。

ほかの言語: [English](README.md), [한국어](README.ko.md), [Deutsch](README.de.md), [Español](README.es.md), [Français](README.fr.md), [Português (Brasil)](README.pt-BR.md), [简体中文](README.zh-CN.md)

## 変わること

### ローンの金利
ローンの金利が「中央銀行金利 + 上乗せ金利」になります。上乗せ金利は世帯の信用格付けで決まります。格付けは AAA から B までの6段階で、次の4つから決まります。資産に対する借金、年収に対する年間返済額、年間支出に対する現金、純資産です。住宅ローンは、住宅価格のうち借りる割合が大きいほど金利が上がります。現在の格付けはローンのウィンドウの金利の横に表示されます。

### 今月末に出ていくお金
月が変わるときに開く月間サマリーの最初の行に「今月末: 必要な現金 $X」と表示されます。ローンの返済額に、前の月末に実際に出ていった賃金や家賃などを足した金額です。

### セーブをロードしたあとの取引ロック
すでに過ぎた月末より前のセーブをロードすると、その月末をもう一度過ぎるまで株式と先物を売買できません。先に見た株価でもうけるのを防ぐ仕組みです。ロックは長くても2か月です。いちばん先まで進んだ月末よりあとに保存したセーブは、ロードしてもロックされません。この機能は設定でオフにできます。

### カジノ
4つのゲームの賭け金と確率が決まります。

| ゲーム | 賭け金 | 当たり |
|---|---|---|
| スロット | $1,000 | 22% の確率で賭け金の3倍が戻り、0.8% の確率で40倍 |
| ルーレット | $10,000 | 44% で2倍、2% で4倍 |
| ブラックジャック | $100,000 | 45% で2倍、2% で2.5倍 |
| バカラ | $1,000,000 | 46.5% で2倍 |

どのゲームも月に1回だけです。お金はゲームが終わるときにまとめて動きます。終わる直前にセーブしてロードを繰り返しても結果は同じです。負けたあとに前のセーブをロードすると、ロード直後に負けた金額がもう一度引かれます。賭け金はゲーム内の物価に合わせて上がります。

### 株式ウィンドウ
会社を選ぶと、最初のタブの金額の横に PBR、PER、配当利回り、前月比の株価変動率が表示されます。リストの会社にマウスを置くだけでも同じ数字が1行で見られます。ゲーム内で調査した会社には適正株価も表示されます。

破産や新株発行が近い会社には警告が付きます。持っている株の会社がその状態なら、月間サマリーにも1行出ます。ゲーム本体は、それが起きたあとにしか知らせません。

リストの会社を Shift+クリックすると、MODがその会社の調査を毎月やり直します。調査のたびに手数料がかかります。Ctrl+Shift+クリックはすべての会社が対象です。

リストの上にある5つの並べ替えボタンのうち4つは、時価総額順、割安順、割高順、前月比の上昇順になります。会社のチャートは株価だけを表示した状態で開き、チャートに6か月表示が加わります。先物リストには品目ごとに現在のインフレ率と予想値が付きます。

### 上場と取締役会
ゲームではビジネスを上場すると株式の 25% だけを受け取り、現金は入りません。MODでは 45% を持ち、残りの 55% を上場価格で売って現金で受け取ります。その現金はその年の課税所得になります。

上場会社の株式を 20% 持つごとに、取締役会の5席のうち1席が保証されます。選挙のある月に世帯のメンバーを指名する必要があります。

### 採用と契約の提案
採用ウィンドウは候補者ごとに実効時給(時給 ÷ 作業効率)を表示し、安い順に並べます。時給 $64.84 で効率 114% の人は $56.88 です。その月の候補者はセーブをロードしても変わりません。

提案された契約の支払いアイコンにマウスを置くと、その仕事の標準コストより何 % 多く支払われるかが表示されます。資産が足りずに作業効率が下がっているビジネスがあれば、月間サマリーが知らせます。

### ビジネスをMODに任せる
ビジネスごとに、次の仕事を1つずつ任せられます。人を採用するとき、広告を出しているとき、契約を結ぶときには、ゲーム内の職業の時給から計算した手数料がかかります。

- 従業員: ゲームの自動管理モード(従業員タブの丸い矢印のアイコン)をオンにします。MODは人手の足りない職務に候補者を採用します。3か月続けて人手が余っている職務では、いちばん高い1人を解雇します。昇給を求められたとき、同じ仕事をもっと安くできる候補者がいればその人に替え、いなければ昇給を認めます。
- 資産: ビジネスで、期限切れのときに新しい資産を自動で購入するチェックボックスをオンにします。MODでは足りない資産も購入します。
- 広告: 広告アイコンを Shift+クリックします。MODは認知度が 103% 未満なら有料広告をオンにし、それ以上ならオフにします。
- 契約: 契約アイコンを Shift+クリックします。MODは月の初めに、標準コストより多く支払う提案を空きがあるだけ結びます。従業員と資産も任せているビジネスでだけ結びます。
- ビジネス全体: 広告アイコンを Ctrl+Shift+クリックします。上の4つをまとめて任せ、フロアスペースが足りないときは賃貸のフロアスペースも広げます。任せているあいだは、そのビジネスを自分で変えるクリック(採用、解雇、資産の売買、契約の受諾と破棄)がロックされます。もう一度 Ctrl+Shift+クリックすると取り戻せます。

ビジネスを閉じているあいだは、もう一度開くまでMODもそのビジネスに何もしません。

### 割安な物件
売りに出ている物件のうち価値より大幅に安いものがあると、月間サマリーが住所と、購入手数料を払ったあとの利益を知らせます。

### 修了した教育
ゲームは学位や認定証の数値を毎月 1% ずつ下げます。5年で 55% ほどしか残らないので、学位を取ってすぐにその仕事を始めないと同じ勉強をやり直すことになります。MODでは、世帯のメンバーが修了した教育は得た分より下がりません。仕事で得た経験は今までどおり下がります。

### 直したゲームの不具合
- ゲームを終了せずにセーブを数十回ロードするとゲームが落ちる問題を直しました。
- 翻訳の誤りを直しました。日本語では、誕生日ウィンドウの文章9つが1つずつずれて表示されていました。数字や日付が入る場所に単語がそのまま出ていた文章も直しました。
- 人名の文字が四角い記号で表示される問題を直しました。

## インストールの前に
- アップデートでゲームのバージョンが変わると、MODは自分でオフになります。新しいバージョン向けの版が出るまでは何も変えません。
- ウイルス対策ソフトが `version.dll` を疑うことがあります。公開されている Ultimate ASI Loader で、ゲームの起動時にMODを読み込むファイルです。
- MODを入れる前から遊んでいたセーブを初めてロードすると、すべてのビジネスで従業員の自動管理モードと資産の自動購入がオフになります。MODではこの2つのスイッチの働きが増えるためです。MODに任せたいビジネスだけオンに戻してください。
- 新しいウィンドウやボタンは増えません。MODの文章はゲームのウィンドウの中に、ゲームの言語で表示されます。

## インストール
1. ゲームを終了します。
2. [Releases](../../releases) からzipをダウンロードし、ゲームのフォルダ(`TGL2.exe` があるフォルダ)に展開します。
3. `RealisticEconomy_install.bat` をダブルクリックします。このファイルは最初にセーブを `saves_before_RealisticEconomy_1` フォルダへコピーします。
4. ゲームを起動します。メインメニュー右下のバージョンのあとに「+ Realistic Economy」が付いていれば、インストールされています。

削除するときは、ゲームを終了して `RealisticEconomy_uninstall.bat` を実行します。MODを入れて保存したセーブは、MODなしでも開けます。

## 設定と詳しい説明
機能は `RealisticEconomy.ini` で1つずつオフにできます。インストールすると `TGL2.exe` の横にできるファイルです。ルールごとの数字と手数料まで書いた説明書は英語版の [docs/RealisticEconomy_README_en.txt](docs/RealisticEconomy_README_en.txt) で、zipの中にも入っています。
