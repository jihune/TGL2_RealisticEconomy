# Realistic Economy

Realistic Economy は This Grand Life 2 のMODです。このMODはゲームのお金のルールを変えます。セーブをロードして利益を得る方法を防ぎます。株式ウィンドウにデータを追加し、ビジネスウィンドウに自動機能を追加します。ゲームの不具合をいくつか直します。

- MODのバージョン: 1.0.0
- ゲームのバージョン: v1.03.22 のみ
- ゲームの開発元が作ったMODではありません。

ほかの言語: [English](README.md), [한국어](README.ko.md), [Deutsch](README.de.md), [Español](README.es.md), [Français](README.fr.md), [Português (Brasil)](README.pt-BR.md), [简体中文](README.zh-CN.md)

## MODがすること

### ローンの金利
ローンの金利は、中央銀行金利に上乗せ金利を足した値です。上乗せ金利は世帯の信用格付けで決まります。信用格付けは AAA、AA、A、BBB、BB、B の6段階です。

MODは次の4つの値から信用格付けを計算します。

- 資産と比べた借金
- 1年の収入と比べた1年の返済額
- 1年の支出と比べた現金
- 純資産

住宅ローンでは、住宅価格のうち借りる割合が大きいと上乗せ金利が高くなります。ローンのウィンドウに信用格付けが表示されます。

### 月末に必要な現金
月間サマリーは、月が変わるときに開くウィンドウです。MODはこのウィンドウの一番上に「今月末: 必要な現金 $X」の行を入れます。この金額は、ローンの返済額と、前の月末に支払ったほかの費用の合計です。賃金と家賃がその費用です。

### ロード後の取引ロック
すでに過ぎた月末より前のセーブをロードすると、MODが取引をロックします。ロック中は株式を買うことも売ることもできません。先物の取引もできません。その月末をもう一度過ぎると、ロックは終わります。ロックは2か月を超えません。

ロックがないと、次の月の株価を見てから古いセーブをロードして株式を買うことができます。この機能は設定ファイルでオフにできます。

### カジノ
MODは4つのゲームの賭け金と確率を固定します。

| ゲーム | 賭け金 | 結果 |
|---|---|---|
| スロット | $1,000 | 22%: 賭け金の3倍を受け取ります。0.8%: 賭け金の40倍を受け取ります。 |
| ルーレット | $10,000 | 44%: 2倍。2%: 4倍。 |
| ブラックジャック | $100,000 | 45%: 2倍。2%: 2.5倍。 |
| バカラ | $1,000,000 | 46.5%: 2倍。 |

- 各ゲームは月に1回プレイできます。
- お金は、カジノの行動が終わるときに入るか出ます。
- セーブしてもう一度ロードしても、結果は同じです。
- 負けたあとに古いセーブをロードすると、MODが負けた金額をもう一度引きます。
- 賭け金はゲームの物価と一緒に上がります。

### 株式ウィンドウ
MODは会社ごとに次の値を表示します。

- PBR
- PER
- 配当利回り
- 先月と比べた株価の変化率
- 適正株価 (ゲームで調査した会社のみ)

会社を選ぶと、最初のタブにこれらの値が表示されます。リストの会社にマウスポインターを置いても表示されます。

破産、規模の縮小、新株の発行が近い会社には警告が表示されます。その会社の株式を持っている場合は、月間サマリーにも警告が表示されます。

調査の購読:

- リストの会社を Shift+クリックしてください。MODが毎月その会社をもう一度調査します。調査1回ごとに手数料を支払います。
- すべての会社を購読するには、会社を Ctrl+Shift+クリックしてください。

そのほかの変更:

- 5つの並べ替えボタンのうち4つの順序が変わります。
  - 時価総額が大きい順
  - 適正株価と比べて安い順
  - 適正株価と比べて高い順
  - 先月からの上昇が大きい順
- 会社のチャートは、株価の線だけを表示した状態で開きます。
- チャートに6か月表示があります。
- 先物リストは、品目ごとにインフレ率と予想インフレ率を表示します。

### 上場と取締役会の席
ゲームでは、ビジネスを上場すると株式の 25% を受け取ります。現金は受け取りません。MODでは、株式の 45% を持ちます。MODは残りの 55% を上場価格で売り、その現金を渡します。この現金はその年の課税所得です。

上場会社の株式 20% ごとに、取締役会の1席が保証されます。取締役会は5席です。選挙のある月に世帯のメンバーを指名してください。指名しないと席は得られません。

### 候補者と契約の提案
採用ウィンドウは、候補者ごとに実効時給を表示します。実効時給 = 時給 ÷ 作業効率。例: $64.84 ÷ 114% = $56.88。リストは、この値が最も低い候補者を最初に表示します。

その月の候補者は、セーブをロードしても変わりません。

契約の提案の支払いアイコンにマウスポインターを置いてください。その提案が仕事の標準コストより何パーセント多く支払うかが表示されます。

ビジネスの資産が足りないと、作業効率が下がります。そのとき、月間サマリーにそのビジネスの名前が表示されます。

### ビジネスの自動化
MODはビジネスの5つの仕事を代わりに行うことができます。仕事ごと、ビジネスごとに開始します。

| 仕事 | 開始の方法 | MODがすること |
|---|---|---|
| 従業員 | ゲームの自動管理モードをオンにします。アイコンは従業員タブの丸い矢印です。 | 従業員が足りない職務に候補者を採用します。3か月のあいだ従業員が余っている職務では、最も高い従業員を解雇します。従業員が昇給を要求すると、より安い候補者に替えます。そのような候補者がいなければ、要求を受け入れます。 |
| 資産 | ビジネスで、新しい資産を自動で購入するチェックボックスをオンにします。 | 足りない資産も購入します。 |
| 広告 | 広告アイコンを Shift+クリックします。 | 認知度が 103% より低いとき、有料広告をオンにします。認知度が 103% 以上のとき、オフにします。 |
| 契約 | 契約アイコンを Shift+クリックします。 | 月の初めに、標準コストより多く支払う提案を結びます。ビジネスに空きがある数だけ結びます。従業員と資産の仕事もオンのときだけ行います。 |
| すべて | 広告アイコンを Ctrl+Shift+クリックします。 | 上の4つの仕事を行います。フロアスペースが足りないとき、賃貸のフロアスペースを増やします。ビジネスを手動で変えるクリックをロックします。 |

- 仕事を止めるには、同じクリックをもう一度行ってください。
- MODは、従業員を採用するとき、広告をオンにしているとき、契約を結ぶときに手数料を取ります。
- 閉じたビジネスには、MODは何もしません。

### 価値より安い物件
売りに出ている物件の価格が価値よりかなり低いとき、月間サマリーに1行が表示されます。その行は住所と利益を示します。利益は、価値から価格と購入手数料を引いた金額です。

### 修了した教育
ゲームは学位や認定証の数値を毎月 1% 下げます。5年後には約 55% が残ります。MODでは、世帯のメンバーが修了した教育の数値は保たれます。職業が要求する最も高い数値を超える部分だけが下がります。仕事で得た経験はゲームと同じように下がります。

### ゲームの不具合の修正
- ゲームを終了せずにセーブを数十回ロードすると、ゲームが終了しました。MODがこの不具合を直します。
- 翻訳が誤っている文章がありました。MODが直します。例: 誕生日ウィンドウの文章が1つずつずれて表示されていました。
- 人名の一部の文字が四角で表示されていました。MODが正しい文字を表示します。

## インストールの前に
- アップデートでゲームのバージョンが変わると、MODは自分でオフになります。新しいバージョンのMODを待ってください。
- ウイルス対策ソフトが `version.dll` を警告することがあります。このファイルは公開されている Ultimate ASI Loader です。ゲームの起動時にMODを読み込みます。
- MODを入れる前のセーブを初めてロードすると、MODはすべてのビジネスで2つのスイッチをオフにします。従業員の自動管理モードと資産の自動購入です。MODでは、この2つのスイッチが行う仕事が増えます。MODに任せるビジネスだけ、もう一度オンにしてください。
- MODはウィンドウやボタンを追加しません。MODの文章は、ゲームのウィンドウに、ゲームの言語で表示されます。

## インストール
1. ゲームを終了してください。
2. [Releases](../../releases) からzipファイルをダウンロードしてください。
3. zipファイルをゲームのフォルダに展開してください。ゲームのフォルダは `TGL2.exe` があるフォルダです。
4. `RealisticEconomy_install.bat` をダブルクリックしてください。このファイルは最初にセーブを `saves_before_RealisticEconomy_1` フォルダへコピーします。
5. ゲームを起動してください。
6. メインメニュー右下のバージョンの文字を見てください。「+ Realistic Economy」があれば、MODはインストールされています。

## 削除
1. ゲームを終了してください。
2. `RealisticEconomy_uninstall.bat` をダブルクリックしてください。

MODを使っているあいだに保存したセーブは、MODなしでも開けます。

## 設定と説明書
- 設定ファイルは `RealisticEconomy.ini` です。インストールのあと、ゲームのフォルダにあります。このファイルで機能を1つずつオフにできます。
- 詳しい説明書は英語です: [docs/RealisticEconomy_README_en.txt](docs/RealisticEconomy_README_en.txt)。ルールの数字と手数料がすべて書いてあります。zipファイルにも入っています。
