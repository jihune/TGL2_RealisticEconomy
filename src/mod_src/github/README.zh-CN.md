# Realistic Economy

这是一个修改 This Grand Life 2 金钱规则的模组。负债多的家庭要付更高的贷款利率。先看下个月的股价，再读取以前的存档去买股票，这个办法不再有用。在赌场输钱后读档重来也一样。股票窗口会多出判断一家公司所需的数字。业务多了以后，费事的招聘、广告和合同可以交给模组。游戏本身的几个问题也一并修复。

仅适用于游戏 v1.03.22。它不是游戏开发商制作的。当前版本是 1.0.0。

其他语言：[English](README.md)、[한국어](README.ko.md)、[Deutsch](README.de.md)、[Español](README.es.md)、[Français](README.fr.md)、[Português (Brasil)](README.pt-BR.md)、[日本語](README.ja.md)

## 改变的内容

### 贷款利率
贷款利率变成“中央银行利率 + 加点”，加点由家庭的信用等级决定。信用等级从 AAA 到 B 共六级，按四项评定：债务与资产之比、一年还款额与一年收入之比、现金与一年支出之比、净资产。抵押贷款中，贷款占房价的比例越大，利率越高。当前等级显示在贷款窗口的利率旁边。

### 本月底要支出的钱
换月时打开的每月总结，第一行会显示“本月底：所需现金 $X”。这个数是贷款还款额，加上上个月底实际支出的工资、租金等费用。

### 读档后的交易锁定
读取一个早于已经过去的月底的存档后，在再次度过那个月底之前，不能买卖股票和期货。这是为了防止用已经看过的股价赚钱。锁定最长两个月。在你到过的最远月底之后保存的存档，读取后不会被锁定。这项功能可以在设置里关闭。

### 赌场
四种游戏的赌注和概率固定下来。

| 游戏 | 赌注 | 中奖 |
|---|---|---|
| 老虎机 | $1,000 | 22% 的概率拿回赌注的 3 倍，0.8% 的概率 40 倍 |
| 轮盘赌 | $10,000 | 44% 的概率 2 倍，2% 的概率 4 倍 |
| 二十一点 | $100,000 | 45% 的概率 2 倍，2% 的概率 2.5 倍 |
| 百家乐 | $1,000,000 | 46.5% 的概率 2 倍 |

每种游戏每月只能玩一次。钱在游戏结束时一次结算。在结束前存档再反复读档，结果都一样。输钱后读取以前的存档，输掉的钱会在读档后立刻再次扣除。赌注随游戏里的物价上涨。

### 股票窗口
选中一家公司后，第一个标签页的金额旁边会显示 PBR、PER、股息率和较上月的股价变化。在列表里把鼠标停在公司上，也能在一行里看到同样的数字。在游戏里研究过的公司还会显示合理股价。

即将破产或增发新股的公司会带有警告。如果你持有这种公司的股票，每月总结里也会有一行提示。游戏本身只在事情发生之后才通知。

在列表里 Shift+点击一家公司，模组就会每月重新研究它，每次研究收取一笔费用。Ctrl+Shift+点击对所有公司生效。

列表上方五个排序按钮中的四个，改为按市值、按低估程度、按高估程度、按较上月涨幅排序。公司的图表打开时只显示股价，图表还增加了 6 个月视图。期货列表里每个品种都会显示当前通胀率和预期值。

### 上市与董事会
在游戏里，业务上市后你只得到 25% 的股份，没有现金。使用模组后你保留 45%，其余 55% 按上市价卖出并以现金付给你。这笔现金算作当年的应税收入。

每持有一家上市公司 20% 的股份，就保证董事会五个席位中的一个。你仍然需要在选举的那个月提名一名家庭成员。

### 招聘与合同报价
招聘窗口会显示每位候选人的每有效小时工资（每小时工资 ÷ 工作效率），并从低到高排列。每小时工资 $64.84、效率 114% 的人是 $56.88。当月的候选人在读档后不会改变。

把鼠标停在合同报价的付款图标上，可以看到它比这份工作的标准成本多付百分之几。如果有业务因为缺少资产而工作效率下降，每月总结会提示。

### 把业务交给模组
每家业务可以把下面的工作分别交给模组。招人、投放广告和签订合同时，会按游戏里某个职业的每小时工资收取费用。

- 员工：打开游戏的自动管理模式（员工标签页里的圆形箭头图标）。模组会为人手不足的职位招聘候选人。某个职位连续三个月人手有余时，解雇其中最贵的一人。员工要求加薪时，如果有候选人能用更低的成本做同样的工作，就换成那个人，没有就同意加薪。
- 资产：在业务里勾选“资产到期时自动购买新资产”的复选框。使用模组后，缺少的资产也会购买。
- 广告：Shift+点击广告图标。知名度低于 103% 时模组打开付费广告，高于这个值时关闭。
- 合同：Shift+点击合同图标。模组在每月初签下报酬高于标准成本的报价，有多少空位就签多少。只有员工和资产也交给模组的业务才会签。
- 整家业务：Ctrl+Shift+点击广告图标。上面四项一次交出，楼层空间不够时模组还会扩大租用的楼层空间。交出期间，手动改动这家业务的点击会被锁定（招聘、解雇、买卖资产、接受和取消合同）。再次 Ctrl+Shift+点击即可收回。

业务关闭期间，在你重新开业之前，模组不会对它做任何事。

### 低于价值的房产
在售房产中如果有价格远低于价值的，每月总结会给出地址和扣除购买费用后的收益。

### 已完成的教育
游戏每月把学位和证书的数值降低 1%。五年后只剩大约 55%，所以拿到学位后不马上从事那份工作，就得把同样的课程再学一遍。使用模组后，家庭成员完成的教育不会降到所得数值以下。工作中获得的经验照旧减少。

### 修复的游戏问题
- 不退出游戏连续读档几十次后游戏会崩溃，这个问题已修复。
- 修正了翻译错误的文字。在多种语言里（包括中文），本该显示数字或日期的地方直接显示了一个词。
- 修复了人名中的字母显示成方框的问题。

## 安装之前
- 游戏更新导致版本变化时，模组会自行关闭。在适配新版本的模组发布之前，它不会改动任何东西。
- 杀毒软件可能会怀疑 `version.dll`。它是公开的 Ultimate ASI Loader，是在游戏启动时加载模组的文件。
- 第一次读取安装模组之前的存档时，所有业务的员工自动管理模式和资产自动购买都会被关闭，因为使用模组后这两个开关做的事情更多。只在想交给模组的业务里重新打开即可。
- 模组不会新增窗口或按钮。模组的文字显示在游戏已有的窗口里，使用游戏的语言。

## 安装
1. 关闭游戏。
2. 从 [Releases](../../releases) 下载 zip，解压到游戏文件夹（`TGL2.exe` 所在的文件夹）。
3. 双击 `RealisticEconomy_install.bat`。它会先把你的存档复制到 `saves_before_RealisticEconomy_1` 文件夹。
4. 启动游戏。主菜单右下角的版本后面带有“+ Realistic Economy”，就说明已经安装。

要移除模组，请关闭游戏并运行 `RealisticEconomy_uninstall.bat`。使用模组时保存的存档在没有模组时也能打开。

## 设置与详细说明
每项功能都可以在 `RealisticEconomy.ini` 中关闭。安装后这个文件在 `TGL2.exe` 旁边。写明每条规则的数字和费用的说明书是英文的 [docs/RealisticEconomy_README_en.txt](docs/RealisticEconomy_README_en.txt)，zip 里也有。
