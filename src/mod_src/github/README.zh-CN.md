# Realistic Economy，This Grand Life 2 模组

版本 1.0.0 · 仅适用于游戏 v1.03.22 · 非官方

[English](README.md) · [한국어](README.ko.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Français](README.fr.md) · [Português (Brasil)](README.pt-BR.md) · [日本語](README.ja.md)

让 This Grand Life 2 里的金钱按更接近现实的规则运转，并且读取以前的存档不再有利可图。模组不新建任何窗口或按钮：它在游戏已有的界面里工作，模组的文字会以游戏的语言显示（八种语言全部支持）。

## 新增内容

### 贷款与现金
- 贷款利率取决于家庭的信用等级（AAA 到 B），抵押贷款还取决于贷款占房价的比例。
- 月度总结会提前显示本月底需要的现金。
- 有房产以远低于其价值的价格出售时，月度总结会提示。

### 读档不再有利可图
- 读取一个早于已经过去的月底的存档后，在再次度过那个月底之前，股票和期货交易会被锁定。
- 赌场游戏有固定的赌注和固定的概率，每种每月一次。结果在读档后保持不变。
- 当月的求职候选人在读档后不会改变。

### 股市
- 每家公司显示 PER、PBR、股息率、较上月的股价变化和合理股价。接近破产或增发的公司会提前警告。
- 研究订阅：Shift+点击一家公司，之后每月会重新研究它。
- 公司上市后你保留 45% 的股份，其余部分以现金支付给你。每持有 20% 保证一个董事会席位。
- 公司列表和期货列表增加了排序方式，图表增加了 6 个月视图。

### 业务
- 招聘窗口显示“每小时工作的成本”（每小时工资 ÷ 工作效率），并从低到高排列。
- 可以把每家业务的工作交给模组：员工（人手不足时招聘、解雇闲置员工、答复加薪要求）、购买缺少的资产、广告、签订合同、扩大楼层空间。一次 Ctrl+Shift+点击可以把整家业务交给模组。

### 修复游戏本身的问题
- 多次读取存档后游戏会退出的问题。
- 游戏翻译中错误或损坏的文字（韩语最多），以及人名中的方框。
- 已完成的教育（学位、证书）每月贬值的问题。

## 安装
1. 关闭游戏。把 Releases 里的 zip 解压到游戏文件夹（`TGL2.exe` 所在的文件夹）。
2. 双击 `RealisticEconomy_install.bat`。它会先把你的存档复制到 `saves_before_RealisticEconomy_1`。
3. 启动游戏。主菜单右下角的版本会显示“v1.03.22 + Realistic Economy”。

要移除模组，请运行 `RealisticEconomy_uninstall.bat`。使用模组时保存的存档在没有模组时也能打开。

## 使用方法
大部分功能会自动运行。需要自己点击的只有下表中的操作，把鼠标停在相应位置时出现的说明文字里也有说明。

| 位置 | 操作 | 作用 |
|---|---|---|
| 股票窗口的公司列表 | Shift+点击一家公司 | 开启或关闭该公司的研究订阅 |
| 同一列表 | Ctrl+Shift+点击 | 开启或关闭所有公司的研究订阅 |
| 业务窗口的广告图标 | Shift+点击 | 把广告交给模组，或收回 |
| 业务窗口的合同图标 | Shift+点击 | 把签订合同交给模组，或收回 |
| 业务窗口的广告图标 | Ctrl+Shift+点击 | 把整家业务交给模组，或收回 |
| 员工标签页的自动管理开关 | 点击 | 为该业务的所有员工切换 |
| 业务的“旧资产自动重购”开关 | 点击 | 模组也会购买缺少的资产 |

每项功能都可以在 `RealisticEconomy.ini` 中关闭。详细说明是 zip 中的英文文件 `RealisticEconomy_README_en.txt`。

## 须知
- 仅适用于游戏 v1.03.22。在其他版本上模组会自行关闭。
- 杀毒软件可能会怀疑 `version.dll`。它是公开的 Ultimate ASI Loader（MIT），在游戏启动时加载模组的文件。
- 与游戏开发商无关的非官方模组。MIT 许可证，源代码在 `src` 中。
