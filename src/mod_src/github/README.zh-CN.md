# Realistic Economy

Realistic Economy 是 This Grand Life 2 的模组。这个模组修改游戏的金钱规则。它阻止通过读取存档来获利的做法。它给股票窗口增加数据，给业务窗口增加自动功能。它修复游戏的几个问题。

- 模组版本：1.0.0
- 游戏版本：仅 v1.03.22
- 这个模组不是游戏开发商制作的。

其他语言：[English](README.md)、[한국어](README.ko.md)、[Deutsch](README.de.md)、[Español](README.es.md)、[Français](README.fr.md)、[Português (Brasil)](README.pt-BR.md)、[日本語](README.ja.md)

## 模组做什么

### 贷款利率
贷款利率等于中央银行利率加上一个加点。加点由家庭的信用等级决定。信用等级有六级：AAA、AA、A、BBB、BB、B。

模组用下面四个数值计算信用等级：

- 债务与资产之比
- 一年的还款额与一年的收入之比
- 现金与一年的支出之比
- 净资产

对于抵押贷款，贷款占房价的比例越大，加点越高。贷款窗口显示信用等级。

### 月底需要的现金
每月总结是换月时打开的窗口。模组在这个窗口的最上面加一行：“本月底：所需现金 $X”。这个金额是贷款还款额与上个月底支付的其他费用之和。工资和租金属于这类费用。

### 读档后的交易锁定
如果你读取一个早于已经过去的月底的存档，模组会锁定交易。锁定期间，你不能买入或卖出股票。你也不能交易期货。你再次度过那个月底后，锁定结束。锁定不超过两个月。

没有这个锁定，你可以先看下个月的股价，再读取旧存档，然后买入股票。你可以在设置文件里关闭这项功能。

### 赌场
模组给四种游戏设定固定的赌注和固定的概率。

| 游戏 | 赌注 | 结果 |
|---|---|---|
| 老虎机 | $1,000 | 22%：你得到赌注的 3 倍。0.8%：你得到赌注的 40 倍。 |
| 轮盘赌 | $10,000 | 44%：2 倍。2%：4 倍。 |
| 二十一点 | $100,000 | 45%：2 倍。2%：2.5 倍。 |
| 百家乐 | $1,000,000 | 46.5%：2 倍。 |

- 每种游戏每月可以玩一次。
- 赌场行动结束时，你得到或失去这笔钱。
- 存档后再读档，结果相同。
- 如果你输了钱，然后读取旧存档，模组会再次扣除输掉的钱。
- 赌注随游戏里的物价上涨。

### 股票窗口
模组为每家公司显示这些数值：

- PBR
- PER
- 股息率
- 与上个月相比的股价变化
- 合理股价（仅限你在游戏里研究过的公司）

选中一家公司，这些数值显示在第一个标签页。你也可以把鼠标指针放在列表里的公司上。

对于接近破产、缩减规模或增发新股的公司，模组显示警告。如果你持有这家公司的股票，每月总结也显示警告。

研究订阅：

- 在列表里 Shift+点击一家公司。模组之后每月重新研究这家公司。每次研究你支付一笔费用。
- 要订阅所有公司，请 Ctrl+Shift+点击一家公司。

其他改动：

- 五个排序按钮中有四个改了顺序：
  - 市值最大
  - 股价相对合理股价最低
  - 股价相对合理股价最高
  - 与上个月相比涨幅最大
- 公司的图表打开时只显示股价线。
- 图表有 6 个月视图。
- 期货列表显示每个品种的通胀率和预期通胀率。

### 上市与董事会席位
在游戏里，你的业务上市后，你得到 25% 的股份。你得不到现金。使用模组后，你保留 45% 的股份。模组按上市价卖出其余 55%，并把现金给你。这笔现金是当年的应税收入。

一家上市公司每 20% 的股份保证一个董事会席位。董事会有五个席位。请在选举的那个月提名一名家庭成员。如果你不提名，就得不到席位。

### 候选人与合同报价
招聘窗口显示每位候选人的每有效小时工资。每有效小时工资 = 每小时工资 ÷ 工作效率。例如：$64.84 ÷ 114% = $56.88。列表先显示这个数值最低的候选人。

当月的候选人在你读取存档后不会改变。

把鼠标指针放在合同报价的付款图标上。模组显示这份报价比工作的标准成本多付百分之几。

如果一家业务的资产不足，它的工作效率会下降。这时每月总结显示这家业务的名称。

### 业务自动化
模组可以替一家业务做五项工作。每项工作、每家业务都要单独开启。

| 工作 | 开启方法 | 模组做什么 |
|---|---|---|
| 员工 | 打开游戏的自动管理模式。它的图标是员工标签页里的圆形箭头。 | 某个职位员工不足时，招聘一名候选人。某个职位连续三个月员工过多时，解雇最贵的员工。员工要求加薪时，换成更便宜的候选人。没有这样的候选人时，接受要求。 |
| 资产 | 在业务里勾选自动购买新资产的复选框。 | 缺少的资产也会购买。 |
| 广告 | Shift+点击一个广告图标。 | 知名度低于 103% 时，打开付费广告。知名度为 103% 或更高时，关闭付费广告。 |
| 合同 | Shift+点击合同图标。 | 每月初签下报酬高于标准成本的报价。业务有多少空位就签多少。只有员工和资产两项工作也开启时才这样做。 |
| 全部 | Ctrl+Shift+点击一个广告图标。 | 做上面四项工作。楼层空间不足时，增加租用的楼层空间。锁定手动改动这家业务的点击。 |

- 要停止一项工作，请再做一次同样的点击。
- 模组在招聘员工、保持广告开启或签订合同时收取费用。
- 对于关闭的业务，模组什么都不做。

### 低于价值的房产
如果一处在售房产的价格远低于它的价值，每月总结显示一行。这一行给出地址和收益。收益等于价值减去价格和购买费用。

### 已完成的教育
游戏每月把学位或证书的数值降低 1%。五年后大约剩下 55%。使用模组后，家庭成员已完成的教育保持数值。只有超过职业最高要求的部分会降低。工作中获得的经验和游戏里一样降低。

### 修复的游戏问题
- 不退出游戏而读取存档几十次后，游戏会关闭。模组修复这个问题。
- 一些翻译文字有错误。模组修正这些文字。例如：有些文字在应该显示数字的地方显示了一个词。
- 人名中的一些字母显示成方框。模组显示正确的字母。

## 安装之前
- 如果游戏更新改变了游戏版本，模组会自行关闭。请等待模组的新版本。
- 杀毒软件可能会对 `version.dll` 报警。这个文件是公开的 Ultimate ASI Loader。它在游戏启动时加载模组。
- 第一次读取安装模组之前的存档时，模组会在所有业务里关闭两个开关。它们是员工的自动管理模式和资产的自动购买。使用模组后，这两个开关做的工作更多。请只在要交给模组的业务里重新打开它们。
- 模组不增加窗口或按钮。模组的文字显示在游戏的窗口里，使用游戏的语言。

## 安装
1. 关闭游戏。
2. 从 [Releases](../../releases) 下载 zip 文件。
3. 把 zip 文件解压到游戏文件夹。游戏文件夹是 `TGL2.exe` 所在的文件夹。
4. 双击 `RealisticEconomy_install.bat`。这个文件先把你的存档复制到 `saves_before_RealisticEconomy_1` 文件夹。
5. 启动游戏。
6. 查看主菜单右下角的版本文字。如果文字里有“+ Realistic Economy”，模组就已经安装。

## 卸载
1. 关闭游戏。
2. 双击 `RealisticEconomy_uninstall.bat`。

使用模组时保存的存档，没有模组也能打开。

## 设置与说明书
- 设置文件是 `RealisticEconomy.ini`。安装后它在游戏文件夹里。你可以在这个文件里关闭每一项功能。
- 完整的说明书是英文的：[docs/RealisticEconomy_README_en.txt](docs/RealisticEconomy_README_en.txt)。它给出规则的所有数字和费用。zip 文件里也有这份说明书。
