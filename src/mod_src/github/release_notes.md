Realistic Economy 1.1.0 for This Grand Life 2, game version v1.03.22.

**New in 1.1.0**: a month end that a load does not change. The game draws a month's economic growth, the industries' cycles and the new share prices from random numbers that a search for a property or an opened window uses up on the way. So loading a save and doing one such thing first gave other share prices for the same month, as often as you liked and without a trade. Now the same month of a playthrough ends the same way whatever you do first, and a listing gets the price its window showed. The properties for sale and for rent that a new month brings, and the month's offer for a property you sell or let, are fixed the same way: they could be loaded away until a bargain came. Going back further than the trade lock's two months gives all of them another course, not only share prices. Switch: `monthEndFixed` under `[guard]` in `RealisticEconomy.ini`.

**Install**: close the game, extract `RealisticEconomy-1.1.0.zip` into the game folder (the one that holds `TGL2.exe`) and double-click `RealisticEconomy_install.bat`. It copies your saves to `saves_before_RealisticEconomy_1` first. To remove the mod, run `RealisticEconomy_uninstall.bat`.

**Coming from 1.0.0**: extract and run the same file. It replaces the mod's files and leaves your settings file as it was (the saves are not copied a second time). The new setting is on even though your settings file has no line for it.

What the mod adds and how to use it is in the README of this repository, in the game's eight languages: English, 한국어, Deutsch, Español, Français, Português (Brasil), 日本語, 简体中文.

The full description is inside the zip (`RealisticEconomy_README_en.txt`, `RealisticEconomy_README_ko.txt`). The SHA256 of the zip is in `RealisticEconomy-1.1.0.zip.sha256.txt`.

An antivirus may question `version.dll`: it is the public Ultimate ASI Loader (MIT), the file that loads the mod when the game starts.
